### 🎨 Design & Flag Inspiration
The visual identity of this map pack is inspired by the **National Flag of Western Sahara**.
* **Hover State:** We utilize a vibrant translucent color (`rgba(0, 120, 60, 0.35)`) to represent the national identity and heritage.
* **Borders:** Rendered in Deep Navy (`#1e293b`) to ensure maximum contrast and a modern, premium aesthetic.

## 💻 How to Render It

Implementing the **Western Sahara** map in your project takes just a few lines of code. Since every map is generated as a plain SVG string, the exact same approach works in **React**, **Vue**, **Angular**, **Svelte**, and **vanilla JavaScript**.

<Admonition type="tip" title="One pattern, every framework">
Generate the SVG with <code>createMap()</code>, inject it into a container, and listen for clicks using the automatic <code>data-code</code> and <code>data-name</code> attributes.
</Admonition>
