## 🏷️ Label Support Summary

- **⚠️ Maps without Labels:** 4

### ⚠️ Important Note on Maps Without Labels

Currently, the following maps **do not support** the `showLabel` feature. If you set `showLabel: true` for these maps, no visual changes will occur:

- 🌍 **`africa`** (Africa)
- 🇪🇺 **`europe`** (Europe)
- 🇮🇷 **`iran`** (Iran)
- 🇺🇸 **`usa`** (United States of America)

#### Why are labels missing for these maps?
This is due to a lack of readily available, high-quality open-source map data, or because we have not yet been able to calculate and verify the correct centroid coordinates for text placement on these specific maps.

</Admonition>
